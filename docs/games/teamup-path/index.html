How to play

Find the shortest Team-Up route

  1. Start with the hero shown on the left.
  2. Choose one available partner to make your next connection.
  3. Follow the arrow direction exactly: A -> B does not automatically mean B -> A.
  4. Reach the target hero using as few moves as possible.

Each connection activates or enhances the current hero's Team-Up ability. The note under a hero shows the benefit for that specific connection.
