# Copyright and Trademark Risk Notes

This is a practical project note, not legal advice.

## Current Risk Level

The project is lower risk when it stays focused on original code, factual game data, and generated team combinations. The main risk increases if the repository or GitHub Pages site includes copied official prose, logos, character art, screenshots, icons, videos, audio, or other assets from Marvel Rivals, Marvel, NetEase, or third-party guide sites.

## Recommended Positioning

- Present the project as an unofficial fan-made utility.
- State that it is not affiliated with, endorsed by, sponsored by, or approved by Marvel, NetEase, or Marvel Rivals.
- Keep hosted data factual and terse: hero names, roles, patch identifiers, partner names, and generated combinations.
- Attribute data sources without copying their expressive text or table presentation.
- Do not include official logos, character portraits, screenshots, UI captures, trailers, audio, or copied ability descriptions unless there is a clear license or permission.
- Do not imply official status in repository text, page copy, package metadata, or deployment descriptions.
- Avoid monetization, ads, paid access, sponsorship messaging, or merchandising around the tool.

## Suggested Disclaimer

This is an unofficial fan-made tool and is not affiliated with, endorsed by, sponsored by, or approved by Marvel, NetEase, or Marvel Rivals. Marvel Rivals, Marvel, character names, and related marks belong to their respective owners. This project uses factual gameplay data for reference and does not include official art, logos, screenshots, video, audio, or copied source prose.
